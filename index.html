Hay Intelligence Pipeline — Open Source Architecture

Hay analysis requires a different spectral approach than corn or soybeans:

  • Multi-cut cycles — Alfalfa yields 3-8 cuttings/year. NDVI must track growth-cut-regrowth cycles, not a single peak
  • NDRE (Red Edge) — Band B05 on Sentinel-2 correlates with chlorophyll content → crude protein proxy. Critical for grade estimation (Supreme vs Good)
  • 8-day composites — Tighter than commodity 16-day composites to capture rapid post-cut regrowth
  • Cutting readiness detection — NDVI threshold + velocity direction signals optimal cut timing
  • Weather window risk — Rain during cutting = quality loss (moldy hay). NDWI trajectory matters as much as NDVI
  • Water rights — Colorado River cuts directly reduce Imperial Valley acreage. Satellite tracks abandoned vs active fields
import pystac_client, planetary_computer as pc, stackstac, numpy as np

catalog = pystac_client.Client.open(
    "https://planetarycomputer.microsoft.com/api/stac/v1",
    modifier=pc.sign_inplace
)

# Columbia Basin alfalfa/timothy node
bbox = [-119.5, 46.5, -118.0, 47.5]
items = catalog.search(
    collections=["sentinel-2-l2a"],
    bbox=bbox,
    datetime="2025-04/2025-10",
    query={"eo:cloud_cover": {"lt": 20}}  # tight for hay quality
).item_collection()

# 4-band stack: Red, Red Edge, NIR, SWIR
stack = stackstac.stack(items,
    assets=["B04", "B05", "B08", "B11"],
    resolution=20  # 20m for field-level detection
)

b4, b5, b8, b11 = [stack.sel(band=b)/10000 for b in ["B04","B05","B08","B11"]]
eps = 1e-10

ndvi = ((b8-b4)/(b8+b4+eps)).clip(-1,1)  # vegetation vigor
ndre = ((b8-b5)/(b8+b5+eps)).clip(-1,1)  # protein proxy (Red Edge)
lswi = ((b8-b11)/(b8+b11+eps)).clip(-1,1) # moisture stress

# 8-day composites (tighter than 16d for multi-cut tracking)
ndvi_8d = ndvi.resample(time="8D").median().mean(dim=["x","y"])
ndre_8d = ndre.resample(time="8D").median().mean(dim=["x","y"])

# Spectral velocity (cutting readiness signal)
velocity = ndvi_8d.diff("time")

# Cutting readiness thresholds (alfalfa)
# ready_to_cut: NDVI >= 0.65 AND velocity turning negative
# post_cut:     NDVI < 0.25
# approaching:  NDVI 0.55-0.65, velocity positive
